Understanding the Form Element

HTML forms provide a way to collect information from users and send it to a server. Two important attributes control where and how the submitted information is delivered.

CODE EXAMPLE / FORM STRUCTURE
<!-- Define form submission settings -->
<form action="/submit" method="POST">

  <input name="username">

</form>
